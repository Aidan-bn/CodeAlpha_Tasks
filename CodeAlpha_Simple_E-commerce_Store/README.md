# CodeAlpha_Simple_E-commerce_Store

This repository it aim to accomplish the project name Simple E-commerce Store providede by Code Alpha Internship program

# Features

the project includes the following functionalities
- Shopping cart
- Product details page
- Order processing
- User registration/login

# Technologies

The following technology were used to build this project
- Frontend: HTML, CSS, JavaScript.
- Backend: Use Django (Python) or Express.js (Node.js).
